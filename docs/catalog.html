Deploy a template

  1. In your Compose Control console, select the Docker host that will run the app.
  2. Open App catalog, choose an app, and select Configure.
  3. Set the stack name and review the template's ports, storage paths, and any required credentials. Check the Compose preview before deploying.
  4. Deploy the app, then open Stacks to find it on the selected host.

This list reflects the server image published as latest on November 9, 2026. Your console shows the templates included in your installed version.
